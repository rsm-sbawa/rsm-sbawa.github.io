SQL Assignment-Checking Agent (Live Demo)

My original was a solo workshop project with Claude and LangChain (89% accuracy). Those files were lost, so I rebuilt the idea as a working agent on a synthetic database.

AI and NLPCompleted

01Problem

Checking SQL homework by reading it is slow and inconsistent. A query can look right and return the wrong rows, or look different and be perfectly correct.

02Approach

The agent follows a plan and uses tools: a safety check, a real SQLite engine running in the browser, a reference solution, a result comparer that allows reordered columns, and diagnosis rules that write targeted feedback and partial credit.

03Impact

Graded all 50 test submissions as intended (20 correct, written several different ways, and 30 with common bugs). I wrote those submissions myself, so this shows the logic works; real student work would be the true test.

Try it

Submit a SQL answer and watch the agent grade it

Synthetic store database: customers (20), orders (36), order_items (68). Pick a question, edit the query and press Grade. Nothing leaves your browser.

    What I did

    • Judges the result, not the wording, so a NOT EXISTS answer and a LEFT JOIN answer both pass.
    • Feedback explains the bug, for example that COUNT(*) counts the empty joined row as 1, or that an inner join drops customers with no orders.
    • Blocks anything that would change the database before running it.
